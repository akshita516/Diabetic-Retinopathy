Deep learning model for the prediction of diabetic retinopathy:

This project is a python based flask application which is used to predict the existing of diabetic retinopathy among individuals. The system includes a login, register, logout page for authentication and a index page where you can apply your retina image and get the results.

The model for the project is saved as model_gaussian.keras. in the model directory.
The dataset is avaliable in kaggle: https://www.kaggle.com/datasets/sovitrath/diabetic-retinopathy-224x224-gaussian-filtered

On this data set various filters are added such as gabor, gaussian, grayscale etc.

The trained models are available in the provided drive link: https://drive.google.com/drive/u/1/folders/1wxFPpZtP4As275yZHagdTRViBAgA4QvS
